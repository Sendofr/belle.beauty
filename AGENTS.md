# Preferencias del usuario

Al terminar un trabajo solicitado sobre esta página web, guardar los cambios en un commit y subirlos al repositorio de GitHub correspondiente. El usuario autoriza este paso habitual sin pedir confirmación cada vez.

Comprobar el remoto y la rama de destino antes de subir; respetar el flujo de ramas del repositorio. No sobrescribir trabajo ajeno ni usar force push. No incluir secretos, dependencias instaladas ni archivos generados que deban permanecer ignorados.

Confirmar que el push terminó correctamente y compartir el enlace del repositorio, commit o pull request. Si no se pudo subir, explicar qué lo bloquea; no presentar cambios locales como publicados en GitHub. Subir el código a GitHub y desplegar la web son acciones distintas.
